# UI Kit – Design System para Help Desk

## Descripción
Este proyecto contiene una librería de componentes de interfaz de usuario (UI Kit) desarrollada con CSS3 puro. Es la base visual para el sistema de gestión de incidentes (Help Desk).

## Componentes incluidos
- **Botones**: primario, secundario, peligro (con estados `:hover`, `:focus`).
- **Formularios**: campos de texto (`input`) y listas desplegables (`select`) con estilos consistentes.
- **Tarjetas (Cards)**: contenedores con sombra y bordes redondeados para mostrar tickets.
- **Alertas (Badges)**: etiquetas de prioridad (Alta, Media, Baja) con colores definidos.

## Tecnologías utilizadas
- HTML5 semántico.
- CSS3 (variables, flexbox, media queries, modelo de cajas).

## Uso
1. Clona el repositorio.
2. Abre el archivo `index.html` en tu navegador para visualizar todos los componentes.
3. Para integrar en tu proyecto, copia las clases CSS en tu hoja de estilos y aplica las clases a tus elementos HTML.
